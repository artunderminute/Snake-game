# Snake Game

A classic Snake game built with HTML5, CSS3, and JavaScript.

## Features

- Classic snake gameplay
- Score tracking with high score persistence
- Increasing difficulty (speed increases every 5 points)
- Smooth animations and modern UI
- Pause/Resume functionality
- Game over screen with restart option

## How to Play

1. Open `index.html` in your web browser
2. Click the "Start Game" button to begin
3. Use the arrow keys to control the snake:
   - **Arrow Up**: Move up
   - **Arrow Down**: Move down
   - **Arrow Left**: Move left
   - **Arrow Right**: Move right
   - **Spacebar**: Pause/Resume
4. Eat the red food to grow and increase your score
5. Avoid hitting the walls or yourself

## Game Rules

- The snake grows by one segment each time it eats food
- The game speed increases every 5 points
- Your high score is saved in the browser's local storage
- The game ends when the snake hits a wall or itself

## Controls

- **Start Game**: Begin a new game
- **Pause**: Pause the current game
- **Reset**: Reset the game to initial state
- **Play Again**: Restart after game over

## Installation

No installation required! Simply:

1. Clone this repository
2. Open `index.html` in any modern web browser
3. Start playing!

## Browser Compatibility

Works in all modern browsers that support HTML5 Canvas and ES6 JavaScript:
- Chrome
- Firefox
- Safari
- Edge
